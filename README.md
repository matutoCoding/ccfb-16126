# 耳模设计工作站（earmold-studio）

纯浏览器端的定制助听器耳模 / 外壳设计系统。**TypeScript + 手写 WebGL2 着色器**，零第三方 3D 库；
客户档案、扫描网格、设计方案、工厂订单全部保存在浏览器本地 **IndexedDB**，数据不出本机。

## 技术栈

- Vite + TypeScript（严格模式，无 any 依赖注入）
- WebGL2：手写 GLSL ES 3.00 着色器，深度剥离（Depth Peeling）顺序无关透明
- IndexedDB：7 个对象仓库，网格以 `Float32Array/Uint32Array` 结构化存储
- Vitest：CPU 几何核心单元测试

## 快速开始

```bash
npm install
npm run dev      # 本地开发（默认 http://127.0.0.1:5180，端口占用自动递增）
npm run build    # 类型检查 + 生产构建
npm test         # 运行单元测试
```

## 透视正确性方案（核心）

### 顺序无关透明
1. **深度剥离**：每个 pass 用单 FBO + MRT 同时写出 `(NDC 深度, 层 ID)`，共用同一深度缓冲，
   保证逐像素深度与 ID 严格一致；共面阈值吸收接缝重叠片元。
2. 各层结果打包进 **2D 纹理数组**（单采样器常量索引），规避 GLSL ES 采样器数组动态索引限制，
   且只占 3 个纹理单元，兼容 `MAX_TEXTURE_IMAGE_UNITS=16` 的设备。
3. **F2B（前到后）精确混合**：片元着色器按剥离纹理软件筛选，公式
   `C' = C + α(1-αAccum)·Cs`，与 CPU 参考实现逐行一致。

### 逐像素壁厚
分析 pass 对相邻 shell 层的相机空间线性深度配对，得到每段壁厚，薄于材料下限处在屏幕上染红；
鼠标悬停可读出该像素每一层的深度与每段壁厚。

### 精度自检（设置页）
- 颜色：GPU 深度剥离合成 vs CPU 逐射线精确排序 F2B 合成，逐像素 RGB 色阶差
- 壁厚：GPU 线性深度（经视线夹角余弦校正回真实毫米）vs CPU Möller–Trumbore 射线求交
- 在层序列 GPU/CPU 严格一致的稳定像素上统计中位数与 P95；复杂凹形轮廓像素单独标记、不混入精度
- 当前结果：颜色中位数 **0.5 色阶**（要求 ≤ 2），壁厚中位数 **0.014mm**（要求 < 0.05mm）

## 目录结构

```
src/
├── core/
│   ├── geometry/   # 印模生成、STL、壳体构建、碰撞、第二弯、自检
│   ├── math/       # 向量/矩阵、网格、扫掠、射线求交、均匀网格加速、CPU 参考渲染
│   ├── render/     # WebGL2 渲染器、GL 封装、GLSL 着色器、轨道相机
│   ├── state/      # 响应式 store
│   └── storage/    # IndexedDB 封装
├── ui/             # 应用外壳、共享视口、六个页面、DOM 工具
└── types.ts        # 全局领域类型
```

## 程序化测试印模

`generateImpression(kind)` 生成四种网格，均为毫米单位封闭扫掠体：
`normal`（正常）、`narrow`（耳道特别窄）、`sharpBend`（第二弯很急）、`bubbleDefect`（带气泡+缺损）。
