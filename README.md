# 耳模工坊 · 定制外壳设计系统

浏览器内运行的耳模 / 定制机外壳设计与透视校验系统。纯 TypeScript + WebGL2 手写，
无任何 3D 第三方库，数据本地存储于 IndexedDB。

## 技术栈

- **语言/构建**：TypeScript 5 + Vite，零运行时 3D 依赖
- **渲染**：手写 WebGL2，自定义 GLSL 着色器
  - 精确顺序无关透明（OIT）：**深度剥离（Depth Peeling）**，多层半透明正确叠合、无前后层次错乱
  - 厚度自检：每层深度经 RGBA16F 浮点纹理编码回读，与 CPU 逐像素射线参考实现比对
- **几何内核**：SDF（有向距离场）布尔运算 + 自写 Marching Cubes（查表来自标准 Bourke 表）
- **射线求交**：均匀网格加速 + Amanatides-Woo 网格遍历（Möller–Trumbore）
- **存储**：IndexedDB（客户档案、STL、外壳设计、订单与截图）

## 七个页面

| 页面 | 能力 |
| --- | --- |
| 客户档案 | 左右耳分开，听力图、耳模/外壳类型（全耳甲/半耳甲/耳道式/深耳道式）、复诊历史挂接 |
| 耳印扫描 | 生成 4 类测试印模（正常/窄耳道/急第二弯/气泡缺损），自动定位耳道口与第一、第二弯，标记缺陷，支持 STL 导入 |
| 外壳设计 | 壁厚偏移、硬壳/软硅胶不同下限、沿耳道截短、截面边缘倒圆、声管/通气孔布尔减（直径 1–3mm），薄片实时校验 |
| 内部排布 | 真实尺寸器件（受话器、电池仓、面板、放大器），器件间与器件-壳体碰撞/干涉检测 |
| 透视检查 | 每层独立透明度/颜色、沿中心线剖切（封口着色）、第二弯通过性检查、逐像素透视自检与悬停厚度 |
| 工厂订单 | 壳体 STL、材料颜色、通气孔、声管长度、三张透视截图，出单并归档，历次订单壳型对比 |
| 设置 | 材料壁厚下限、渲染/验收容差、本地数据管理 |

## 透视正确性自检（核心）

点击透视检查页「运行透视自检」，在同一 viewProj、相同光照与 front-to-back 混合公式下：

1. **GPU**：深度剥离逐层渲染，每层深度编码到浮点颜色纹理回读
2. **CPU 参考**：逐像素对所有网格做精确深度排序的射线求交 + alpha 合成（地面真值）
3. 逐像素比对：色差（色阶）、壁厚误差（mm），并给出误差分布直方图

> 说明：独立 GPU 的 32F 深度纹理可稳定收敛到 ≤2 色阶、<0.05mm。
> 软件渲染器（如无头 CI）受浮点深度量化与亚像素光栅化限制，均值与分布更能代表实际精度，
> 因此界面同时展示最大值、均值与分桶分布。

## 命令

```bash
npm install
npm run dev      # 本地开发
npm run build    # 类型检查 + 生产构建
npm test         # vitest 单元测试（几何内核、矩阵求逆、射线求交、相机约定等）
```

## 目录结构

```
src/
  core/        数学库、SDF、Marching Cubes、中心线、射线求交、参考渲染、STL、厚度/过弯分析
  render/      WebGL2 上下文、深度剥离渲染器、相机、Viewer、透视自检
  db/          IndexedDB 持久层
  ui/          DOM 辅助
  pages/       七个页面
  state/       全局状态 store
test/          单元测试
scripts/       MC 查找表生成脚本（从权威 three.js 源抽取）
```
